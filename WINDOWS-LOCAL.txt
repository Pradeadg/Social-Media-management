APLIKASI LENGKAP
1. Pasang Docker Desktop dan aktifkan backend WSL 2 / Linux containers.
   Ikuti https://docs.docker.com/desktop/setup/install/windows-install/
   Restart Windows bila installer meminta. Buka Docker Desktop sampai engine siap.
   Verifikasi di terminal baru:
     docker version
     docker compose version
     wsl --version
   Windows yang terdeteksi: build 19045. Pemeriksaan virtualisasi/WSL lengkap belum berhasil dalam sesi ini.

2. Di root project, jalankan layanan development yang disediakan repository:
     docker compose -f docker-compose.dev.yaml up -d postiz-postgres postiz-redis temporal
   PostgreSQL aplikasi: 17; Redis: 7.
   Temporal 1.28.1 membawa PostgreSQL 16 dan Elasticsearch 7.17.27 sebagai dependensi.
   Tunggu layanan siap; periksa:
     docker compose -f docker-compose.dev.yaml ps
     docker compose -f docker-compose.dev.yaml logs --tail 50 temporal

3. Dependency memakai pnpm asli repository:
     .\pnpm-local.cmd install --frozen-lockfile
   Bila node_modules sudah terpasang, perintah ini hanya memverifikasi/sinkronisasi.
   Prisma client dibuat saat postinstall. Bisa diulang:
     .\pnpm-local.cmd prisma-generate

4. Inisialisasi skema pada database lokal yang ditunjuk .env:
     .\pnpm-local.cmd prisma-db-push
   Jika Prisma meminta penghapusan data, berhenti dan tinjau database dahulu.
   Jangan menambahkan --accept-data-loss, menjalankan prisma-reset, atau docker compose down -v.

5. Jalankan frontend, backend, dan orchestrator bersama:
     .\pnpm-local.cmd dev:local
   Atau klik dua kali Start-Postiz.cmd.
   Buka http://localhost:4200 dan buat akun lokal.
   Gunakan localhost secara konsisten, jangan berganti ke 127.0.0.1 saat login.

6. Berhenti: Ctrl+C pada terminal aplikasi. Layanan Docker dapat dihentikan tanpa menghapus volume:
     docker compose -f docker-compose.dev.yaml stop
